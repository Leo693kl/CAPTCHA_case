# T03 — карта, карточка и метрики

**Версия 1, 19.11.2026.** Предлагаемый владелец — Леонид.

**Зона.** `src/components/MapSurroundings.tsx`, новый `src/components/EvidenceMetrics.tsx`, `src/styles/surroundings.css` и согласованный CSS нового компонента. `App.tsx` правит интегратор по запросу с точным изменением props.

**Выход.** Человек находит контакт, понимает роль, видит основания для следующего разговора и сохраняет контекст, когда открывает историю или меняет фильтр.

1. Добавить в карточку явные предпочтения, последний релевантный конкурентный опыт и источник. Показывать дату, подпись источника, причину со слов контакта, переход к записи. При нескольких записях брать последнюю подходящую по выбранной дате и выводить доступные предыдущие в истории.
2. Показать метрики T01 в карточке и кратком обзоре. Указать область, период, числа и пустое состояние. Соотнести с фильтрами и историей по контракту, сохранить существующие линзы, путь знакомства, охват, риск и список связей.
3. Использовать существующие токены и компоненты. Проверить 1366×768 и 1920×1080, длинный текст, фокус, клавиатуру, пустой фильтр, состояние без наблюдений. Иллюстрировать динамику имеющейся историей людей, где прошлые рёбра не реконструированы.

**Приёмка.** S1, S3 и S4. Пользователь видит причину и автора без поиска по документам, получает корректное различие между нулём и отсутствием данных, возвращается к текущей дате, фильтр не ломает карту. `npm test`, `npm run build`.
