## Подключение в App.tsx

```tsx
import { MapLegend, MapSelectionLabel } from './components/MapLegend';
import {
  MapEvidenceSignals, MapIndicators, RelationStrengthEvidence, SupplierLines,
} from './components/MapEvidence';
import type { MapSlice } from './types';

const slice: MapSlice = {
  companyId, asOf: activeDate, historical, selectedPersonId: selected,
  people, relations, interactions, snapshots,
};
```

Передавай состав компании и срез до применения фильтров людей. В `.map-area` замени прежний `.map-legend` на `<MapLegend lens={lens}/>`, а после `ReactFlow` добавь `<MapSelectionLabel slice={slice} relation={relation}/>`. В класс активного ребра добавь `map-edge-active`, сохранив `path-highlight` для маршрута. Текущие линии между людьми отображаются без стрелок.

Под графом, после `.map-area` в `.map-content`, добавь:

```tsx
<SupplierLines slice={slice} companyName={company.name} onOpenSource={onOpenSource}/>
<MapIndicators slice={slice} onOpenSource={onOpenSource}/>
```

Над историей карты:

```tsx
<MapEvidenceSignals slice={slice} onOpenPerson={selectPerson} onOpenSource={onOpenSource}/>
```

В существующем `PersonDetails` добавь проп `mapEvidence={{slice, onOpenSource, sourceInteractionId}}`. Поле `sourceInteractionId` необязательно. При открытии доступного источника установи выбранный контакт и ID записи, а при возврате восстанови исходную карточку или линию. Карточка сама раскроет, выделит и сфокусирует найденную запись. Если добавляется отдельная кнопка наблюдения на карте, её якорь `data-tour="observation-entry"`. До этого тур подсвечивает «Входящие». Нумерация пяти шагов сохраняется.

В карточке ребра:

```tsx
<RelationStrengthEvidence
  slice={slice}
  relation={relation}
  onOpenSource={onOpenSource}
  onConfirmStrength={beginRelationStrengthConfirmation}
/>
```

`beginRelationStrengthConfirmation` получает `{ kind: 'relation-strength', relationId, strength }`. Направь его в форму подтверждения наблюдения о паре. При отправке вызови `saveInteraction(slice.companyId, draft, change)` с устойчивым `requestId` и подтверждённым фрагментом в `draft`. Отказ закрывает форму без изменения карты. По одному свидетельству предложение отсутствует. По двум разным подтверждённым записям о той же паре предлагается 3/5, верхняя граница правила — 5/5. Для активации ребра с клавиатуры передай тот же обработчик открытия в `Edge.domAttributes.onKeyDown` на Enter и пробел. Клик продолжает вызывать его через `ReactFlow.onEdgeClick`.
