Предыдущие исправления источников, интервью, валидации хранилища и двух вкладок сохранены в истории. Новая ветка не объединена с MVP/main.

Основание — [дизайн-спека и оба оригинала](../../design/kapcha-2026-11-19/SPEC.md). Основной эталон — красно-зелёный; синий сохранён для происхождения, но позднее текстовое задание прямо выбрало красный. `docs/12-design-contract.md` ссылается на новый эталон. Тёмная палитра заменена светлой по прямому заданию пользователя, без копирования вымышленных данных изображения.

## Что изменилось

- Одна тонкая шапка; слева легенда и единственный набор фильтров, центр — граф, справа — контакт/компания. На 1440×900 измерено **232 px слева, 356 px справа, граф 852×672,5 px**. Колонки прокручиваются независимо. История и маршрут раскрываются снизу, сигналы/поставщик — справа. Дубли фильтров в шапке не создавались; dropdown и поиск используют то же состояние App.
- Новая палитра, размеры колонок, типографика, интервалы, радиусы и акценты — в `tokens.css`; единый светлый режим. Красная основная кнопка, красные контур/подпись выбора, зелёная шкала теплоты. Убрано прежнее затемнение графа открытой панелью, тяжёлые фоны и фоновые сетки. Ключевые текстовые пары: контраст **16,32:1**, вторичный текст **6,47:1**, красный на фоне **5,27:1**, белый на красной кнопке **5,51:1**. Это проверка конкретных пар, не полная сертификация WCAG.
- Сохранены planOrbit, данные, линзы, масштабирование/перетаскивание ReactFlow, фильтрация, источники, API, локальное хранение и расчёты. Автоматическая подгонка кадра адаптирована к настоящим границам сцены; выбор не увеличивает карту до потери общего контекста. Размер видимой точки по-прежнему зависит от влияния. Подписи не уменьшаются до нечитаемого текста при обзоре; реальная кнопка узла имеет область нажатия не менее 24 px на экране, проверен физический клик рядом с видимой маленькой точкой.
- `ContactOverview` показывает настоящее имя, роль/отдел/должность; дату/канал последнего касания; «Как общаться» с теплотой, позицией, динамикой снимков и подтверждёнными предпочтениями; короткую цитату и источник; основное действие; действующие связи; показатели компании. Полная карточка PersonDetails, история, редактирование, бриф и маршрут доступны через раскрытие.
- Новый read-only `communicationPreferences` выбирает последнее непустое подтверждённое поле данного собеседника и хранит ID его источника. Упоминание Белова не переносит ему предпочтения Титова. При разных источниках полей доступны соответствующие ссылки. Пустой канал скрыт; пустые новые поля не стирают ранее подтверждённые. Два новых теста проверяют происхождение, компанию/дату, порядок записей и отсутствие мутации.

`git diff e8ea2fb -- src/api src/data src/types.ts src/lib/orbitLayout.ts src/lib/mapMetrics.ts src/lib/mapSignals.ts src/lib/warmPath.ts` пуст: действующие транзакции, данные, алгоритмы и метрики не менялись.

## Снимки 1440×900 и отличия от макета

[Общий граф](../../after/redesign-map-1440.png) · [Титов и «Как общаться»](../../after/redesign-titov-1440.png).

Сопоставлены три колонки, площадь центрального графа, тонкие разделители/светлая палитра, читаемость выбранного имени, порядок карточки и положение основной кнопки. Ширины находятся в заданных диапазонах, граф не затемняется открытой карточкой. Причины заметных отличий:

1. **Реальные люди/отделы/связи и их расположение.** У Титова «Бизнес», а не «Проекты»; в текущих данных у него одна связь с Анной Орловой. Ирина Белова — автор со стороны КРОК, не добавлена в люди банка. Показаны 30 настоящих контактов и действующая радиальная раскладка, поэтому точки расположены иначе, чем иллюстрация.
2. **Размеры точек и подписи.** Влияние Титова — 1/5, поэтому его заливка меньше, чем у людей с большим влиянием. Красный контур/подпись и отдельная область нажатия делают выбор доступным без подмены влияния. На общем виде постоянно подписаны ЛПР, остальные имена доступны при наведении/фокусе; полное выбранное имя есть в графе и карточке.
3. **«Как общаться» добавлен по текстовому уточнению.** Реальная динамика Титова — 3→4 с датами 01.12.2025–30.04.2026; формат/темы — из только что сохранённого интервью. Блок и источник занимают место, поэтому нижние показатели/полная история при необходимости читаются прокруткой правой колонки.
4. **Линзы и служебные возможности сохранены.** Компактная полоса линз и раскрытия истории/маршрута занимают часть высоты графа; они не удалены ради буквального повторения статичного рисунка. Пунктир подписан «неформальная», исправляя условную «слабую связь» на макете.

## Локальный запуск и передача

Порт 4176 занят прежним preview. Итоговый сервер запущен из CAPTCHA_case и **оставлен включённым** на **4179**:

```sh
npm test
npm run build
pnpm exec vite preview --host 127.0.0.1 --port 4179 --strictPort
```

Адрес: `http://127.0.0.1:4179/?company=bank&demo=2026-11-19`. На текущем Mac pnpm 10 вызван через временный PATH к уже установленному CLI; глобальные установки не менялись. Показ требует JavaScript и локального HTTP. В свежем профиле интервью надо сохранить, чтобы появились его предпочтения; в оставленном тестовом браузере запись создана настоящей формой и открыта карточка Титова.

Команде нужны Node 22+ и pnpm 10, затем `git fetch origin`, `git switch feat/kapcha-redesign`, `pnpm install --frozen-lockfile` и команды выше. Ветка отправляется обычным push; PR — из `feat/kapcha-redesign` в `mvp/kapcha-19nov`, без автоматического слияния. Полный SHA сборки получается через `git rev-parse HEAD` и фиксируется в локальном манифесте/ответе; самоссылка коммита в документ не вставляется.

Ограничения MVP прежние: синтетика, localStorage одного профиля/origin, Web Locks для безопасной записи, нет рабочей CRM/внешней модели. Полная сертификация доступности и новый полный аудит всех сценариев S0–S9 не заявляются.
