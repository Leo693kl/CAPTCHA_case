# Ограничения прототипа

- Реальная CRM, сервер и многопользовательская синхронизация отсутствуют. Изменения и подтверждённое состояние имитации хранятся в localStorage браузера (`src/api/crmApi.ts`).
- Историческая карта восстанавливает контакты по снимкам, но использует текущие связи между существующими на выбранную дату людьми (`src/lib/history.ts`, `src/App.tsx`).
- Теплота, влияние и сила связи задаются пользователем; автоматического расчёта оценок по истории нет (`src/App.tsx`, `src/types.ts`).
- Входящие предложения извлекаются локальными правилами и ключевыми словами; языковая модель или внешнее API не подключены (`src/lib/llmExtractor.ts`, `src/components/Incoming.tsx`).
- Сигналы концентрации и конфликтов касаний являются эвристиками и не доказывают фактической зависимости или конфликта (`src/lib/signals.ts`).
- Подтверждение записи заменяет данные выбранной компании в локальной имитации CRM; реальной отправки нет (`src/components/Integration.tsx`, `src/api/crmApi.ts`).
- Значения полей JSON после чтения приводятся к TypeScript-типу без полной runtime-валидации. При ошибке чтения базового состояния используется исходный набор (`src/api/crmApi.ts`).
