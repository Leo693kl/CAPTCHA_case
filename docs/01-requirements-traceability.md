# Соответствие требованиям кейса

Статусы относятся к прототипу; исходные требования — `docs/case.md`.

| Требование | Реализация | Файлы | Статус |
|---|---|---|---|
| Выбор клиента | Список компаний переключает карту | `src/App.tsx`, `src/data/crm.json` | Полностью |
| Карта людей | Секторы, кольца, карточки и масштаб | `src/App.tsx`, `src/lib/orbitLayout.ts` | Полностью |
| Связи | Тип, сила, просмотр и редактирование | `src/App.tsx`, `src/types.ts` | Полностью |
| Оценка отношений | Ручные теплота и позиция | `src/App.tsx`, `src/types.ts` | Полностью |
| История взаимодействий | Просмотр записей в карточке; форма создания отсутствует | `src/components/MapSurroundings.tsx` | Частично |
| Редактирование | Контакты и связи; не все поля контакта есть в форме | `src/App.tsx` | Частично |
| Фильтрация | Имя, подразделение, роль, позиция, владелец, давность | `src/components/MapSurroundings.tsx`, `src/App.tsx` | Полностью |
| Обмен с CRM | Предпросмотр и подтверждение в локальную имитацию | `src/components/Integration.tsx`, `src/api/crmApi.ts` | Частично |
| Аналитика | Охват, риски, белые пятна и линзы | `src/lib/coverage.ts`, `src/lib/signals.ts`, `src/lib/lenses.ts` | Полностью в пределах эвристик |
| Путь знакомства | Поиск по связям от тёплого контакта | `src/lib/warmPath.ts` | Частично: оценки субъективны |
| Историческая карта | Снимки людей; связи текущие | `src/lib/history.ts`, `src/components/TimeControls.tsx` | Частично |
| Разбор текста | Предложения по правилам и подтверждение | `src/lib/llmExtractor.ts`, `src/components/Incoming.tsx` | Частично: модели ИИ нет |
| Справка к встрече | Сведения о человеке и история | `src/components/MeetingBrief.tsx` | Полностью в пределах данных |
| Демо, клавиши, темы | Экскурсия, справка, переключение темы | `src/components/DemoTour.tsx`, `src/components/Shortcuts.tsx`, `src/App.tsx` | Полностью |
| Совместная работа и синхронизация | Отсутствуют | `src/api/crmApi.ts` | Нет |

Продажи используют роли и маршрут; маркетинг — линзу согласий и интересов; проектные и производственные команды — историю и линзы проектов и технологий; руководство — охват и сигналы зависимости (`src/lib/lenses.ts`, `src/lib/signals.ts`, `src/components/MeetingBrief.tsx`).
