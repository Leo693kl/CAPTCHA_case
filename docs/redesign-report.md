# Финальный отчёт о редизайне

Дата проверки: 16.11.2026. Проверка выполнена на локальных демонстрационных данных; для крайних случаев и снимка пути использовались временные данные в изолированной сессии браузера.

## Что изменено

- Повышен контраст хлебных крошек, бейджа прототипа и подписей колец за счёт существующих цветовых токенов.
- Добавлены позиция контакта в aria-label узла, русские подписи связей и видимая подсветка линии связи при клавиатурном фокусе. Esc закрывает поповер охвата; проверено также закрытие карточки и подтверждения удаления.
- Исправлен перенос длинных имён и должностей в боковой панели. Заданы исходные размеры узлов React Flow, чтобы их отображение не зависело от задержки измерения.
- Production-сборка разделена на чанки React, графа и приложения; проверен запуск собранной версии через Vite preview.
- Созданы снимки трёх клиентов, шести линз, фильтров, панели человека, интеграции и режима пути в `docs/after/final-*.png`.

## Результаты проверки

1. **Контраст — частично.** Автоматическое сравнение вычисленных цветов видимого HTML-текста на карте, в открытой панели контакта и на экране интеграции не обнаружило пар ниже WCAG AA после исправлений. Это не полная проверка всех состояний: SVG, полупрозрачные элементы, все сочетания фильтров, анимации, иконки и наложения требуют отдельного ручного аудита. При полном обзоре карты подписи всё ещё слишком малы.
2. **Клавиатура — частично.** Проверены Tab до связей, видимый фокус на связи, русское имя связи, aria-label узла, Esc для карточки, подтверждения удаления и поповера охвата. Полный аудит всех состояний и комбинаций скринридеров не проведён; порядок обхода большого числа связей и узлов требует отдельной проверки с пользователями.
3. **Размеры — частично.** На 1280×720, 1366×768 и 1920×1080 ширина документа и шапки не превышала ширину окна; высота шапки — 56 px. На 1280 px панель с длинным именем не имела горизонтального переполнения. Боковая панель всё ещё перекрывает часть карты, а подписи общего плана малы; полную визуальную проверку каждого экрана на каждом разрешении нельзя считать завершённой.
4. **Консистентность — частично.** По поиску в собственных CSS/TS/TSX вне `tokens.css`: HEX и вызовов rgb/rgba/hsl/hsla — 0; прямых литералов семейства шрифта в `font-family`/`fontFamily` — 0; вхождений чисел с единицами px/rem/em/vh/vw/vmin/vmax — 702. Последнее число включает толщины линий, размеры текста и геометрию; поиск не учитывает числовые JSX/SVG-значения, поэтому не является полным количеством хардкод-размеров. Миграция размеров и единый ритм не завершены.
5. **Крайние случаи — выполнено для проверенных сценариев.** В изолированных данных проверены 5 и 40 контактов, пустой результат фильтра, длинные неразрывные имена и должности, отсутствие истории. В отдельной проверке 40 контактов с 16 видимыми длинными подписями пересечений подписей друг с другом и с кругами не обнаружено. Это не доказывает отсутствие пересечений при любом наборе данных.
6. **Производительность и сборка — частично.** Все 20 существующих тестов проходят. TypeScript и Vite собраны напрямую без предупреждений, production preview открыл 30 узлов. В окружении отсутствует команда npm, поэтому точная команда `npm run build` не выполнялась. JS: 688 571 байт (gzip по файлам: 174 853); CSS: 144 487 байт (gzip: 47 584). Дополнительно Vite сформировал 72 файла шрифтов общим размером 851 980 байт; браузер загружает нужные подмножества, а не обязательно все. Подсветка при наведении использует изменение CSS-классов и не вызывает React state update; узлы мемоизированы. Полный профайл React каждого сценария не проводился.
7. **Скриншоты — выполнено.** Файлы `final-map-bank.png`, `final-map-retail.png`, `final-map-industry.png`, `final-lens-1.png`…`final-lens-6.png`, `final-person.png`, `final-filters.png`, `final-integration.png`, `final-path.png` находятся в `docs/after/`.
8. **Отчёт — выполнено.** Создан этот файл с ограничениями и результатами.

## Файлы этого прохода

- `src/App.tsx` — доступные имена узлов и связей, Esc для поповера, исходные размеры узлов.
- `src/styles/surroundings.css` — контраст шапки и переносы длинного текста.
- `src/styles/map.css` — контраст подписей колец и фокус связи.
- `vite.config.ts` — разделение production-бандла.
- `docs/after/final-*.png` — снимки Playwright.
- `docs/redesign-report.md` — этот отчёт.

## Известные недостатки

Размеры и отступы во многих существующих стилях остаются литералами. Контраст и фокус не проверены исчерпывающе во всех состояниях. При полном масштабе карты текст подписей мелкий; автоматического смещения подписей при произвольных коллизиях нет. Маркетинговый экспорт и сигнал об устаревании не реализованы в проекте и не добавлялись. `npm run build` требует установленного npm; в этой среде проверены его эквивалентные команды `tsc -b` и `vite build`.
