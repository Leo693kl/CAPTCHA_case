# Тестирование

Запуск: `npm test` или `pnpm test`; сборка отдельно — `npm run build`. Тесты используют встроенный `node:test` (`package.json`).

| Файл | Проверки |
|---|---|
| `tests/coverage.test.mjs` | Пустой набор, компоненты, граница 365 дней, изоляция данных |
| `tests/history.test.mjs` | Снимки, одинаковая дата, удаление, события |
| `tests/hoverHighlight.test.mjs` | Соседи, направления рёбер и очистка |
| `tests/integration.test.mjs` | Разбор предложений и diff |
| `tests/orbitLayout.test.mjs` | Пересечения и размещение в полосах |
| `tests/signals.test.mjs` | Зависимости, пропущенные роли и конфликты касаний |
| `tests/warmPath.test.mjs` | Веса, выбор старта и недостижимость |

Тесты проверяют функции, а не полный пользовательский интерфейс; автоматические браузерные, интеграционные тесты реальной CRM и процент покрытия в репозитории не представлены.

Проверка при подготовке документации: `npm test` — 20 тестов пройдено, ошибок и пропусков нет.

## Ручная регрессия

| Сценарий | Действия и ожидаемый результат |
|---|---|
| Клиент | Переключить компанию: название и контакты меняются |
| Карта | Масштабировать, выбрать узел: открывается карточка человека |
| Связи | Выбрать линию: видны тип и сила; добавить связь между разными контактами |
| Оценки | Изменить теплоту и влияние, сохранить: данные и внешний вид узла обновляются |
| История общения | Открыть контакт: отображаются имеющиеся записи и даты |
| Редактирование | Создать, изменить, удалить контакт; обновить страницу: рабочие данные сохраняются |
| Фильтры | Найти имя и выбрать роль: неподходящие контакты приглушены; сбросить фильтры |
| Линзы и охват | Переключить линзу, раскрыть охват: кольца и компоненты соответствуют данным |
| Белые пятна и риски | Открыть сигнал: отображается объяснение и предлагаемые точки входа |
| Маршрут | Выбрать цель: путь подсвечен или сообщается об отсутствии |
| Историческая карта | Выбрать прошлую дату: видны снимки, редактирование отключено; вернуться к текущей дате |
| Входящие | Подставить пример, разобрать, проверить и принять предложение: карта обновляется |
| CRM | Изменить контакт, открыть предпросмотр и подтвердить: локальная базовая копия обновляется |
| Доступность | Проверить фокус, клавиатуру, переключение темы и reduced motion |

Источники поведения: `src/App.tsx`, `src/components/Incoming.tsx`, `src/components/Integration.tsx`, `src/components/TimeControls.tsx`. Ручной чек-лист является инструкцией, а не отчётом об исполнении.
