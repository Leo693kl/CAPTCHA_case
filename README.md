## Запуск

Нужны Node.js 22 и pnpm 10. Установите pnpm согласно [инструкции pnpm](https://pnpm.io/installation), затем выполните в папке проекта:

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес, который выведет Vite, обычно http://localhost:5173/.

```bash
pnpm test       # тесты
pnpm build      # проверка TypeScript и сборка в dist/
```

Реального сервера CRM нет: прототип использует тестовые данные и хранит изменения в localStorage браузера. У каждого пользователя свои данные.

Карта отображает роли, позиции и связи людей, помогает оценить охват и найти путь к контакту. Доступны фильтры, линзы, исторические снимки, разбор входящего текста и локальная имитация записи изменений в CRM (`src/App.tsx`, `src/components/Integration.tsx`).

## Как это связано с кейсом КРОК

Кейс предусматривает карту структуры принятия решений и отношений, а также демонстрацию возможного обмена с CRM (`docs/case.md`). В проекте используются тестовые данные и локальная имитация CRM.

## Структура проекта

```text
src/api/         имитация CRM
src/components/  экранные компоненты и UI
src/data/        демонстрационные данные
src/lib/         алгоритмы и преобразования
src/styles/      стили и токены
src/App.tsx      главный экран
src/types.ts     модель данных
tests/           тесты node:test
docs/            кейс и документация
```

## Работа в команде

Для текущего MVP исходный commit и ветку назначения PR задаёт [очередь задач](docs/plans/INDEX.md). Создавайте отдельную ветку на пакет. Перед объединением запускайте тесты и сборку, а изменения просите проверить другого участника. Не коммитьте `node_modules`, `dist`, локальные настройки и секреты.
