# Карта ЛПР

Прототип интерактивной карты участников принятия решений для кейса КРОК. Требования находятся в [docs/case.pdf](docs/case.pdf), текстовая копия — в [docs/case.md](docs/case.md).

## Запуск

Нужны Node.js 22 и pnpm 10. Установите pnpm согласно [инструкции pnpm](https://pnpm.io/installation), затем выполните в папке проекта:

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес, который выведет Vite, обычно http://localhost:5173/.

```bash
pnpm test       # тесты
pnpm build      # проверка TypeScript и сборка в dist/
```

Реального сервера CRM нет: прототип использует тестовые данные и хранит изменения в localStorage браузера. У каждого пользователя свои данные.

## Работа в команде

Начинайте задачу с актуальной ветки `main`, создавайте отдельную ветку и открывайте pull request в `main`. Перед объединением запускайте тесты и сборку, а изменения просите проверить другого участника. Не коммитьте `node_modules`, `dist`, локальные настройки и секреты.
