## Цель
Кликабельный прототип страницы «Карта ЛПР», которая открывается из карточки
компании в CRM. Показывает структуру принятия решений и отношений, а не оргструктуру.

## Стек
Vite, React, TypeScript, Tailwind, @xyflow/react, Zustand. Без бэкенда:
слой src/api/crmApi.ts имитирует REST CRM (async, задержка 150–400 мс),
данные в src/data/*.json, правки в localStorage.

## Правила
- Строгий TypeScript, без any. Компоненты маленькие, логика графа в src/lib/.
- Интерфейс на русском. Даты в формате ДД.ММ.ГГГГ.
- Никаких дефолтных «шаблонных» градиентов и фиолетово-синего AI-стиля.
- После каждой задачи: npm run build без ошибок, краткий отчёт что изменено.
- Не менять файлы вне задачи. Не добавлять зависимости без причины.
- Доступность: контраст, фокус с клавиатуры, aria-label на узлах.

## Доменная модель
Company, Person (department, title, decisionRole: decision_maker | influencer |
evaluator | user | blocker, stance: champion | supporter | neutral | skeptic,
influence 1–5, interests[], consentMarketing), Relation (from, to, type:
reports_to | works_with | informal, strength 1–5), Interaction (personId, date,
channel, ourOwner, ourDepartment, summary, sentiment), PersonSnapshot для истории.
## Визуальная идентичность

**Уточнение для `feat/kapcha-redesign` (прямое задание пользователя 19.11):** действуют белый фон, зелёные и фиолетовый акценты и Manrope из уточнения 20.11 в [спеке](docs/design/kapcha-2026-11-19/SPEC.md). Тёмная палитра ниже описывает прежнюю MVP, не возвращать её в редизайн. Точка продолжения и непроверенное — [передача 20.11](docs/plans/CONTEXT-2026-11-20.md).
Стиль вдохновлён фирменным стилем КРОК, но не копирует его.
- Тема: тёмная «радарная диспетчерская», основной фон #08151D.
- Главный акцент: зелёный #00A460 (кнопки, активные состояния, тёплые связи). Текст на зелёном всегда тёмный #08151D.
- Вторичные: светло-голубой #8ED1FC (подписи, ЛПР), синий #475DEB (линии, влияющие). Синий НЕ использовать как цвет текста на тёмном фоне.
- Шрифты: Golos Text (интерфейс), IBM Plex Mono (числа, метрики, подписи колец). Действующий источник — `src/styles/tokens.css`.
- Графика: тонкие линейные паттерны (радиальные лучи секторов, дуги связей), мягкий mesh-градиент зелёного и синего с низкой непрозрачностью на фоне.
- Логотип КРОК не использовать. В шапке только текст «Карта ЛПР · CRM КРОК».
- ВСЕ цвета, отступы, радиусы и тайминги только через переменные из src/styles/tokens.css. Хардкод-цвета в компонентах запрещены.
- Запрещено: фиолетово-синие градиенты, glassmorphism везде, шаблонный вид SaaS, эмодзи вместо иконок.
- Иконки: lucide-react, толщина линии 1.75.

## Правила редизайна
- Перед правкой интерфейса и перед сдачей открой [правила дизайна и визуальной проверки](docs/design/interface-review.md). Пройди затронутые сценарии в браузере и сверяй текст, отступы, состояния и фокус по этому документу.
- Логику, данные, алгоритмы раскладки, API-слой не менять без прямой просьбы.
- После каждой задачи: npm run build без ошибок и список изменённых файлов.
- Контраст текста не ниже WCAG AA. Видимый фокус с клавиатуры везде.
- Уважать prefers-reduced-motion.
- Корректный вид на 1366×768 и на 1920×1080.
